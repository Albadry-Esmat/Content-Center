7 Golden Rules (Long‑Form)

  • Don't make the viewer wait for the value. Start with the strongest point.
  • Explain → Question → Answer → New Question → Proof → New Insight. Create forward momentum.
  • Use the “BUT” mechanism: Expectation → BUT → Reality.
  • Give an early indication of your perspective.
  • Don't hide all value until the end.

3 Short / Reel Master Structure

HOOK (0–3s) ↓ PROBLEM / CURIOSITY (3–10s) ↓ CONTEXT (5–15s) ↓ CORE INSIGHT (10–35s) ↓ PROOF / DEMO ↓ PAYOFF (35–50s) ↓ CTA (5–10s)

The structure matters more than the exact number of seconds.

4 Hook Types

Contrarian “Most D365 developers misunderstand this.”
Mistake “If you're registering your plugin like this, you're creating a problem.”
Curiosity “Something happens between Save and plugin execution most devs never see.”
Result “This one change dramatically improved how we handled this.”
Question “What actually happens when you update a Dataverse record?”
Challenge “See if you can answer this before I explain it.”
AI “AI can generate the code—but can it understand your Dataverse architecture?”

The hook should be immediately understandable, target the audience, create curiosity, promise value, and avoid unnecessary introductions.

5 Pre‑Launch vs Post‑Launch

⏳ Pre‑Launch Short

Goal: Create curiosity. Do not give the complete answer.

“You think [assumption]. But actually [truth]. So what actually happens? I break down the complete flow in the full video.”

📤 Post‑Launch Shorts

Goal: Deliver standalone value. Each Short delivers one clear piece of value.

#1 Insight · #2 Mistake · #3 Tip · #4 Advanced · #5 Question

8 Short Golden Rules

  • Hook fast — do not waste the first seconds.
  • One Short = One Idea — do not cram a whole tutorial into 60s.
  • Teach something — don't sacrifice education for clickbait.
  • Create curiosity before the long video
  • Give value after the long video — post‑launch Shorts work independently.
  • Do not spoil the long video
  • Show, don't only tell — technical audiences respond to visible proof.
  • Every sentence earns its place — remove filler.
  • Adapt the CTA — one CTA does not fit every platform.
  • Build content systems — one strong topic generates multiple pieces.
